# 🌐 Vault of Codes – AICTE Web Development Internship

A collection of frontend web development assignments and projects completed as part of the **Vault of Codes – AICTE Internship Program**.

This repository showcases practical implementation of HTML, CSS, and JavaScript concepts through portfolio pages, interactive forms, landing pages, and a simple online booking interface.

---

## 📌 About the Internship

The internship focused on developing foundational frontend web development skills through practical assignments and project-based learning.

The repository contains the original work completed during the internship, organized to demonstrate the concepts and features implemented in each task.

## 🎯 Objectives

- Understand the fundamentals of HTML and CSS.
- Build structured and visually appealing webpages.
- Practice responsive web design.
- Implement interactive functionality using JavaScript.
- Work with forms, user input, and DOM manipulation.
- Gain practical experience in frontend development.

## 💻 Assignments and Projects

### 1. Personal Portfolio Website

A static personal portfolio webpage created using HTML and CSS.

**Features:**
- About Me section
- Skills and interests
- Projects and certificates
- Contact information
- Styled content sections

### 2. Vault of Codes Internship Landing Page

A promotional webpage designed to showcase internship opportunities.

**Features:**
- Internship introduction
- Multiple internship category links
- CSS hover effects
- Flexbox-based layout
- Responsive styling

### 3. Certificate Verification Interface

A frontend certificate verification interface developed using HTML, CSS, and JavaScript.

**Features:**
- Email or numeric ID input
- Basic input validation
- Dark mode toggle
- Loading spinner animation
- Success notification
- Enter-key support

*Note: This is a frontend demonstration. It does not perform verification against an actual certificate database.*

### 4. Enhanced Personal Portfolio (FA1)

An extended version of the personal portfolio assignment.

**Features:**
- Personal introduction
- Skills and interests
- Certificate listing
- Project information
- Additional project card component

### 5. User Registration Form (FA2)

An interactive registration form created using HTML, CSS, and JavaScript.

**Features:**
- Personal information fields
- Email and password inputs
- Date of birth and gender selection
- Profile picture input
- Terms and conditions checkbox
- Dynamic password strength indicator

### 6. Online Booking System

A simple frontend booking interface that allows users to enter booking details and view a confirmation message.

**Features:**
- Customer information form
- Service selection
- Date and time selection
- Form validation
- Dynamic booking confirmation
- Automatic form reset

*Note: This is a frontend demonstration. It does not include backend processing or persistent booking storage.*

## 🚀 Getting Started

No additional software installation or package dependencies are required.

**Steps to run the projects:**

1. Clone this repository:

```bash
git clone https://github.com/Ankitahota22/WEBDEV_vault-of-codes_AICTE.git
```

2. Open the downloaded project folder.

3. Navigate to the assignment or project HTML file.

4. Open the HTML file in any modern web browser.

5. Explore the webpage and its available functionality.
